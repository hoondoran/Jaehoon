## 3. 금액적 특이사항 · 이슈

### ★ 이슈 1 — 원표 '전년반영률' 열이 76건 오류 (최우선)

`전년반영률(C/D)` 열을 전수 검산한 결과 **76건이 실제값의 정확히 절반**으로 기재돼 있습니다.

```
예) 옥포읍 간경리 502
    전년공시지가 C = 651,200 / 전년시가수준 D = 1,040,000
    실제 C/D   = 0.6262  (62.6%)
    원표 기재   = 0.3162  (31.6%)   ← 절반
```

| 읍면리 | 오류 건수 |
|---|---:|
| 옥포읍 기세리 | 29 |
| 옥포읍 본리리 | 27 |
| 옥포읍 간경리 | 10 |
| 옥포읍 신당리 | 8 |
| 옥포읍 송촌리 | 1 |
| 화원읍 본리리 | 1 |
| **합계** | **76** |

거의 전부 **옥포읍**에 몰려 있습니다. 시가수준_A ÷ 전년시가수준 비율이 오류군 1.0046 / 정상군 1.0050으로 **동일**하므로, 시가수준 값은 정상이고 **반영률 열만 잘못 산출**된 것으로 확인됩니다.

**그대로 제출하면** 해당 76필지가 반영률 31~36%로 보여 "왜 여기만 현실화율이 절반인가"라는 질문을 반드시 받습니다. 제출 전 재계산이 필요합니다.
